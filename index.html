🔥 Kết Nối Firebase

Bảng tin này đã được kết nối sẵn tới dự án Firebase databasesclass-3a085. Bạn chỉ cần gửi file này cho cả lớp — ai mở cũng thấy chung một bảng tin, vì dữ liệu nằm trên Firebase chứ không phải trên máy từng người.

Lưu ý: dự án Firestore cần đang ở chế độ cho phép đọc/ghi (test mode hoặc rules phù hợp) thì mọi người mới đăng bài/nhắn tin được. Nếu là lớp trưởng/quản trị dự án, vào console.firebase.google.com → dự án databasesclass-3a085 → Build → Firestore Database → Rules để kiểm tra hoặc chỉnh lại nếu cần.

rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /posts/{postId} { allow read, create: if true; allow update, delete: if true; match /comments/{commentId} { allow read, create, delete: if true; } } match /classChat/{msgId} { allow read, create, delete: if true; } } }

Bảng tin lớp dùng chung một cơ sở dữ liệu Firebase (Firestore) nên mọi bài đăng, ảnh, lượt thích và bình luận đều cập nhật theo thời gian thực cho tất cả mọi người.
Vì đây là bảng tin dùng chung công khai trong lớp nên đừng đăng thông tin quá riêng tư nhé.
